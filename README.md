# Dhruv Rathod Portfolio

Personal portfolio website showcasing my frontend, backend, and full-stack development projects.

## Live Website

https://dhruvportfolio-nu.vercel.app/

## Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- React Icons
- Vite

## Features

- Modern responsive design
- Project showcase
- Skills section
- Education timeline
- Achievements section
- Resume download
- Contact information

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
